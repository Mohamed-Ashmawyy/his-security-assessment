# Security and Disclosure Policy

This repository is a sanitized portfolio artifact and does not contain production code, credentials, tokens, personal data, client identifiers, or exploit-ready evidence.

Do not use the material in this repository to test or interact with any real system. Security testing must be performed only with explicit written authorization and within an agreed scope.

If you identify a secret or sensitive detail that was accidentally included, do not reproduce it publicly. Remove the artifact from the repository history where possible, rotate the affected secret immediately, and notify the repository owner through a private channel.

The original engagement material was confidential and remains restricted to authorized stakeholders.
