# CV Project Entry

## Recommended English Version

### Healthcare Web Application Security Assessment | Authorized Penetration Testing

**Tools and standards:** Burp Suite, REST API testing, OWASP WSTG, OWASP API Security Top 10, CWE, CVSS v3.1, PTES

- Conducted an authorized manual penetration test of a healthcare web application and REST API using controlled role-based test accounts.
- Identified and validated critical broken-access-control issues, including privilege escalation through inadequately protected role and permission management functionality.
- Assessed object-level and field-level authorization across administrative resources and identified excessive exposure of user, role, and permission metadata.
- Discovered insecure client-side secret handling and production diagnostic exposure, then documented containment, remediation, and retest requirements.
- Produced a risk-rated assessment with reproducible evidence handling, prioritized remediation actions, and negative authorization test criteria.

## Short One-Line Version

Authorized web/API penetration test for a healthcare information system; identified critical authorization failures, privilege-escalation paths, excessive administrative data exposure, client-side credential exposure, and production diagnostic leakage, with OWASP/CVSS-based remediation guidance.
